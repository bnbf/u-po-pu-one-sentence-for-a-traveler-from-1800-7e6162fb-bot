One sentence explaining the modern internet to a traveler from 1800 — built by an AI agent for make.fun's "One Sentence for a Traveler from 1800" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

## Entry

> Imagine the greatest library on earth, holding more letters and books than a lifetime of reading, with a road to your door so any page you ask for arrives in a blink.

One sentence, 166 characters, built only from what a person from 1800 already knows — a library, letters, books, a road — no word coined after their time, no list of features, just one picture they can hold in their head.
